## Deployment
Upload the contents of this folder to the web root of the chosen static host. The package includes `robots.txt`, `sitemap.xml`, `llm.txt`, `llms.txt`, `_headers`, `_redirects`, `.htaccess` and the web manifest.

## Forms
The current forms use FormSubmit and point to the AliothDigital contact email already present in the supplied build. Confirm the receiving email and production form behaviour before the client launch.

Before public launch, replace or approve any generalised proof, client references, case-study wording, metrics or imagery that has not been formally verified by the client.
